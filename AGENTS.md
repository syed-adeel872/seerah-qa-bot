## Two-Layer Safety Guardrail

### Layer 1: Deterministic Blockers (Pre-Retrieval)

**File:** `web/src/lib/guardrails/blockers.ts`

30+ regex patterns evaluated BEFORE any retrieval or generation:

- **Fatwa patterns:** `fatwa`, `halal`, `haram`, `makruh`, `qaza`, `qada`, `namaz timing`, `roza`, `zakat`, `nikah`, `talaq`, `wudu`, `ghusl`, `jummah`, `mahr`, `iddat`, `sawm`, `salat`, `sajdah`, `khitan`, `janazah`, `zabihah`, `qurbani`, `ta'wiz`, `bid'ah`, `shirk`, `qasam` + Urdu script + Roman Urdu variants
- **Injection patterns:** `ignore previous instructions`, `you are now`, `reveal system prompt`, `jailbreak`, `developer mode` + Urdu script variants

When matched: immediate refusal with tri-language text + scholar redirect. No retrieval, no generation.

### Layer 2: Post-LLM Refusal Inspection (Post-Generation)

**File:** `web/src/lib/engine/answer.ts`

26 regex patterns that detect LLM-generated refusals:

- English: `shari'i masla`, `religious ruling`, `consult a qualified scholar`, lazy fallbacks, scope hedging
- Roman Urdu: `daaira-e-kaam mein nahi`, `mustanad aalim`, `tafseel nahi`
- Urdu script: `شرعی فتویٰ`, `مستند عالم`, lazy fallbacks
- System prompt leakage: `system prompt`, `my rules are`, `i am told to`

When detected: `status` → `"blocked"`, `citations` → `[]` (stripped).

### Layer 3: Frontend Citation Gating

**File:** `web/src/components/chat/chat-client.tsx`

```typescript
const showCitations = answer.status === "answered" && answer.citations.length > 0;
```

Hides SourceChips, ShareButton for all non-"answered" responses.

## Multilingual Support

### Languages

| Language | Detection | Mirroring |
|----------|-----------|-----------|
| English | Default fallback | → English |
| Urdu Script | Arabic char detection `[\u0600-\u06FF]` | → Urdu |
| Roman Urdu | 90+ marker dictionary | → Roman Urdu |

### Trilingual Conflation

76 conflation groups unify English + Urdu + Roman Urdu for retrieval:

```
clothing = {clothing, clothes, libas, kapra, لباس, کپڑا, ...}
```

### Transliteration

- `web/src/lib/l10n/translit.ts` — Urdu→Roman transliteration (16 KB)
- Roman Urdu titles prefer corpus's own `slug.romanUrdu`
- Body text generated by `urduToRoman`

## LLM System Prompt Rules

### English (`SYSTEM_PROMPT_EN`)

1. FATWA REDIRECT — refuse ruling queries, redirect to scholar
2. OUT-OF-CORPUS REDIRECT — refuse non-Seerah topics
3. SEMANTIC SYNTHESIS — "Think like a researcher, not a search engine"
4. LASER-FOCUSED — answer only the specific question
5. STRICT BAN ON LAZY FALLBACKS — never say "I don't have details" when passages exist
6. BASE ONLY ON CONTEXT — no external knowledge
7. NO INTERNAL THOUGHTS — no bracketed reasoning
8. NO FLUFF — just answer

### Roman Urdu (`SYSTEM_PROMPT_ROMAN_UR`)

Same 9 rules adapted for Roman Urdu, including mandatory context usage and Rule 9 (Script Purity — Latin-only output).

### Urdu (`SYSTEM_PROMPT_UR`)

Same 9 rules adapted for Urdu script, including post-LLM refusal enforcement.

## UI Component Protections

### Components That Must NOT Be Removed

| Component | File | Purpose |
|-----------|------|---------|
| `CopyButton` | `chat-client.tsx` | Clipboard copy with fallback |
| `ShareButton` | `chat-client.tsx` | WhatsApp share / clipboard |
| `SourceChips` | `chat-client.tsx` | Interactive clickable citation badges |
| `SourceModal` | `chat-client.tsx` | Citation detail modal (Hawala, titles) |
| `AssistantBubble` | `chat-client.tsx` | Bot response wrapper |
| `Disclaimer` | `disclaimer.tsx` | Persistent footer disclaimer |

### Components That Should NOT Be Rendered

| Component | Reason |
|-----------|--------|
| `SourceList` | Redundant plain-text reference list below chips — removed to avoid duplicate citation display |

### Layout Requirements

- Persistent header (fixed, never scrolls)
- Flex-column layout: header → scroll area → composer → disclaimer
- Bot messages flush left (aligned with input box)
- User messages right-aligned
- Disclaimer always visible below chat input
- Dark theme with radial gradient background
